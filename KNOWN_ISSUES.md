# Known Issues

Current public release: `0.1.0-alpha.1`.

- The public runtime still depends on GitHub Actions -> SSH and requires a target reachable from GitHub-hosted runners.
- Laptop/private-device outbound execution is not part of the current public release.
- Private/device Ajint repositories have evolved beyond this public architecture in places; their behavior must not be assumed to be supported here.
- Interfaces may still change during the `0.x` developer-preview period.

These are current-state notes, not commitments to a specific future design.
