# Roadmap

## Current stable line

- Keep `0.1.0-alpha.1` understandable, reproducible and supportable.
- Preserve current public Actions -> SSH behavior until a separately reviewed release changes it.
- Keep release, security and compatibility documentation accurate.

## Next candidates

- Evaluate proven downstream Issue Runner work for possible future promotion.
- Define a public protocol/version boundary before any transport migration.
- Add migration and regression gates before a future runtime release.

## Not part of this baseline

- No Issue Runner migration.
- No version bump.
- No installer/workflow changes.
- No automatic migration of historical tasks.
